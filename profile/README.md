# MASKINREPUBLIKEN

## *ny teknik för det allmänna*

Namnet kommer av *res publica*, det allmänna. Maskiner för det gemensamma är verktyg som den som använder dem också äger: koden går att läsa, data går att ta med sig, och driften går att flytta till någon annan. Vi bygger dem små och långlivade, eftersom det som ska bära gemensam verksamhet måste gå att underhålla av andra än oss.

## SÅ ARBETAR VI

- Drift i Sverige eller EU.
- Öppna dataformat och full dataexport, alltid.
- Exitplan i varje avtal, skriven innan kunden frågar.
- Öppen källkod där det går.
- Ingen kunddata tränar modeller. En människa fattar besluten som får konsekvenser.
